Tech Stack
Chosen for a tiny, offline, no-install Windows utility.

.NET 8 WPF: transparent, borderless, hardware-accelerated HUD.

WinForms NotifyIcon: reliable tray support WPF lacks.

WH_KEYBOARD_LL: system-wide input without plugins.

SQLite: private local history in one file.

DynamicResource tokens: all nine themes repaint instantly.

Key Mechanics
Three tricks define the product's honesty and speed.

Rolling buffer: 310-second retention; 150 ms recalculation timer.

Net WPM: max(0, typed − backspaces × (1 + penalty)) ÷ 5 ÷ active minutes.

5m stitching: gaps ≤ 3.5 s count as continuous typing; longer gaps are reading pauses.

Session save: only after ≥ 5 keystrokes and ≥ 1.5 s.

Keep WPF for the overlay; enable WinForms only for NotifyIcon.

Rejected: pure WPF had no dependable tray icon without extra dependencies.

Local-First SQLiteDECIDED BY HUMAN
All history stays in a local file; no accounts, network, or cloud.

Rejected: cloud sync added login friction, privacy risk, and cost.

Code: DatabaseService.cs → InitializeDatabase, SaveSession
Net WPM With Error PenaltyDECIDED BY HUMAN
Count net correct characters, not raw keystrokes.

Rejected: gross WPM let backspacing and mashing inflate the score.

Code: TypingEngine.cs → CalculateWindowWpm, EndSession · AppSettings.cs → ErrorPenaltyMultiplier
Dynamic Theme TokensAGENT · APPROVED
Shared luminance-aware brushes replace hardcoded per-window colors.

Rejected: hardcoded colors produced white-on-white dropdowns and invisible labels.

Code: ThemeManager.cs → ApplyTheme · App.xaml → AppSurfaceBrush, AppTextPrimaryBrush
Burst-Stitched 5-Minute WPMDECIDED BY HUMAN
Divide words by active typing time, not wall-clock time.

Rejected: wall-clock division punished legitimate pauses for reading or thinking.

Code: TypingEngine.cs → CalculateSustained5mWpm
Source-Only Repo, Tag ReleasesDECIDED BY HUMAN
Keep binaries out of git; publish the portable exe through Releases.

Rejected: committing six exes added roughly 387 MB to history and slowed every clone.

Code: .gitignore → releases/ · .github/workflows/release.yml → publish-portable

Do not touch

Each rule prevents a specific bug from returning. Full detail: docs/DECISIONS_AND_TRAPS.md.

Settings Initialization OrderDO NOT TOUCH
Never build the temp settings clone after InitializeComponent.

What breaks: XAML slider coercion raises ValueChanged early; a null temp object crashes Settings and hides the overlay.

Protected: SettingsWindow.xaml.cs → constructor, _isInitializing, SliderOpacity_ValueChanged
Assembly-Qualified Pack URIsDO NOT TOUCH
Always keep /WPMOverlay;component/ in icon URIs.

What breaks: testhost and secondary assemblies resolve short URIs against the wrong assembly and throw “Cannot locate resource”.

Protected: MainWindow.xaml, SettingsWindow.xaml, HistoryWindow.xaml → Icon
WPF / WinForms Type CollisionsDO NOT TOUCH
Keep every Wpf-prefixed alias while both frameworks are enabled.

What breaks: Application, Color, MessageBox, and MouseEventArgs become ambiguous (CS0104).

Protected: App.xaml.cs, ThemeManager.cs, HistoryWindow.xaml.cs, MainWindow.xaml.cs → aliases
ComboBox Popup TokenizationDO NOT TOUCH
Never replace DynamicComboBoxStyle with a stock ComboBox.

What breaks: the native popup paints a white surface, causing contrast inversion on dark themes.

Protected: SettingsWindow.xaml → DynamicComboBoxStyle, CmbPreset
Auto-Hide Grace TimerDO NOT TOUCH
Never hide directly on mouse-leave or settings-close.

What breaks: the configured 1–15 second delay is ignored and the HUD vanishes instantly.

Protected: MainWindow.xaml.cs → _autoHideGraceTimer, TriggerAutoHideGracePeriod, Window_MouseLeave, OpenSettingsWindow
Anti-Spam ThresholdsDO NOT TOUCH
Do not loosen 30 ms, 2 repeats, 25 characters, or the 6-key oscillation check.

What breaks: held keys and mashing generate fake 300+ WPM records and corrupt all history.

Protected: TypingEngine.cs → IsValidTypingKeystroke · TypingEngineTests.cs → SmartFiltering_*
SQLite WAL SidecarsDO NOT TOUCH
The .db file is not the only artifact; -wal and -shm travel with it.

What breaks: copying only the main file can lose recent sessions; deleting a locked database can corrupt it.

Protected: DatabaseService.cs → constructor, InitializeDatabase · .gitignore → *.db-wal, *.db-shm
Hook Must Never BlockDO NOT TOUCH
Keep HookCallback tiny and always call CallNextHookEx.

What breaks: database or UI work in the hook causes system-wide typing lag; skipping the next hook can swallow keys.

Protected: KeyboardHook.cs → HookCallback, Start · TypingEngine.cs → OnKeyPressed
